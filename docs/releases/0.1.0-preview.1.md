# iMirror v0.1.0 — Windows x64 preview 1

**UNSIGNED DEVELOPMENT PREVIEW. Clean-Windows validation is pending.**

Recommended user asset: **iMirror-v0.1.0-windows-x64.zip**. Extract everything,
open START-HERE.html for Vietnamese/English instructions, then run iMirror.exe.
No Rust, Cargo, Git, Python, Node, Visual Studio or FFmpeg CLI runtime is needed.
The corresponding-source ZIP is for developers and license compliance; it is
not the app download. Preserve all DLLs and AirPlay/WDA folders.

## Included

- Native Rust/Win32 UI, English/Tiếng Việt, aspect-matched video window.
- USB and Wireless mirroring; Bluetooth relative mouse/keyboard control.
- Optional managed WDA, including automatic preparation of a privately registered
  compatible developer image after phone restart.
- USB native DLLs/helper, application-local Microsoft VC runtime, private
  UxPlay/GStreamer runtime, WDA native helpers and license notices.
- Offline Bluetooth/WDA guides, official Sideloadly link and Configure-WDA.cmd.

## Validation and limitations

The exact EXE SHA256 is
`4aaffa975e13580c584fa9d1974952367e7a91713ab151fa56cee1b1cd2fc6c3`.
It passed fmt, strict Clippy, 82 default Rust tests, 26 overlapping WDA all-feature
tests and release build. On the tested iPhone15,4 / iOS 27.0 / Windows 11 host,
reopening this EXE after phone restart automatically mounted the registered image
and a user-confirmed WDA click succeeded over Wireless video.

USB mirroring, Bluetooth/Raw Input, Wireless video and WDA tap/list-swipe behavior
have prior physical test evidence. Packaging does not change those binaries;
that prior evidence is not a new complete hardware suite or a clean-PC test.
Exact extracted-package startup/import checks are recorded separately in the
release verification asset. Windows 10 and other Bluetooth adapters/iOS versions
are not universally validated. Actual FPS/resolution/latency vary; no guaranteed
60 FPS. Audio is disabled. WDA swipes execute after mouse release, not realtime.

Bluetooth uses iPhone AssistiveTouch; it does not need Apple ID, Developer Mode
or a companion app. WDA requires a separately signed/trusted phone runner,
Developer Mode, USB pairing and compatible developer image. Use Wireless video
with USB reserved for WDA on the tested configuration. Windows reboot, held-open
app recovery across phone reboot, sustained recovery and clean installation remain
untested. Apple driver software must be obtained through official Apple channels.

Sideloadly is not bundled because redistribution permission has not been established.
Signed IPA, Apple images, Apple drivers, accounts and pairing records are excluded.
No credentials from the developer's machine are reusable setup for another user.
The separate MIT go-ios CLI is the hash-pinned official release asset with dirty
revision metadata; exact reconstruction of that upstream binary is not claimed.
The iMirror GPL forwarder dependency sources accompany the source archive.

This project is independent of Apple, Microsoft and Sideloadly. iMirror is
GPL-3.0-only; other bundled components retain their licenses. Read the full
notices and source information supplied with the release.

Published as a public pre-release at the repository owner's explicit request.
Clean-Windows validation remains a gate for a broadly supported stable release.
The ZIP retains its original packaging-time draft checklist; publication does
not change its binary bytes or turn untested checks into passes.
No installer/uninstaller is supplied by this portable release. To remove it,
close iMirror and delete the extracted folder; private settings remain in LocalAppData.
